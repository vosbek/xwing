# Controls

Default bindings live in `godot/scripts/Controls.cs`. Where we believe the original used a key,
we use it; those are marked *(orig?)* until they're verified against the manual or the game.

| Action | Keyboard | Gamepad / joystick |
|---|---|---|
| Pitch (nose up / down) | ↓ / ↑ | Left stick Y |
| Yaw | ← / → | Left stick X |
| Roll | Q / E | Right stick X |
| Fire lasers | Space | A / button 1 |
| Throttle 0 / ⅓ / ⅔ / full | Backspace / `[` / `]` / `\` *(orig?)* | — |
| Throttle ±10% | `=` / `-` *(orig?)* | RB / LB |
| Cycle fire-link mode | X *(orig?)* | X |
| Next / previous target | T / Y *(orig?)* | Y |
| Nearest enemy | R *(orig?)* | B |
| Laser recharge level | F9 *(orig?)* | — |
| Shield recharge level | F10 *(orig?)* | — |
| Shield focus (even / fore / aft) | S | — |
| Lasers → shields / shields → lasers | `;` / `'` | — |
| Hyperspace | H | — |
| Cockpit / chase view | V | — |
| Music on / off | M | — |
| Pause | P | — |
| Restart mission | F5 | — |
| Quit | Esc | — |

Remapping UI and HOTAS throttle-axis support are on the roadmap.
